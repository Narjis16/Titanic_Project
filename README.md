 Titanic Survival Prediction

Project Overview
Built a machine learning model to predict passenger survival on the Titanic using Python. Achieved "80.45% accuracy" with logistic regression.

 Key Steps
- Cleaned 177 missing age values
- Handled missing embarkation data
- Converted categorical variables (gender → 0/1)
- Built and evaluated logistic regression model

Results
- "74%" of females survived vs only "19%" of males
- Model accuracy: "80.45%"

 Business Insight
The 55% gender survival gap identifies clear targeting opportunities for safety messaging or resource allocation.

Tools Used
- Python
- Pandas (data cleaning)
- Scikit-learn (logistic regression)
- Seaborn/Matplotlib (visualization)

How to Run
1. Open in Google Colab or Jupyter Notebook
2. Run all cells sequentially
3. View accuracy output
